# Pipeline ETL en Power BI: Ventas TechStore

## 📌 Descripción del Proyecto
Este proyecto consiste en la construcción de un pipeline ETL (Extracción, Transformación y Carga) para la empresa **TechStore**, desarrollado en **Power BI Desktop** utilizando **Power Query** y **Lenguaje M**. 

El objetivo principal es tomar los datos crudos del sistema de ventas desde un origen de datos Excel, realizar un perfilado completo para resolver problemas de calidad de datos (duplicados, nulos e inconsistencias de formato), y desnormalizar la tabla de hechos para construir un modelo de datos limpio y confiable orientado al análisis posterior.

---

## 🛠️ Tecnologías y Herramientas Utilizadas
* **Power BI Desktop:** Para la ingesta de datos, modelado e integración.
* **Power Query / Lenguaje M:** Para la limpieza, transformación, combinación y documentación técnica del pipeline.
* **Git / GitHub:** Para la gestión de versiones y entrega del proyecto.
